### About me

I'm an early-career developer who hasn't picked one niche yet, so I build things in different areas and see what sticks.

- Python backends with FastAPI and PostgreSQL
- Object detection with YOLO, from labeling data to training
- Local LLMs through Ollama
- Team projects and hackathons, including C# and ASP.NET Core at the Alfa-Bank one

Пока не выбрал нишу: пробую разное и собираю проекты.
